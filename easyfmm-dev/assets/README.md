# ⚽ EasyFMM (Easy Football Manager)

**EasyFMM**은 웹 브라우저에서 즐길 수 있는 차세대 축구 매니지먼트 시뮬레이션 게임입니다. 감독이 되어 팀을 이끌고, 전술을 수립하며, 이적 시장을 통해 최강의 스쿼드를 구축해 보세요!

---

## 🚀 주요 기능

### 1. 정교한 매치 엔진 및 시각화
*   **RealSoccerEngine**: 선수들의 위치, 스태미나, 개인기, 전술 상성을 실시간으로 계산하는 정밀한 매치 엔진.
*   **Match Visualizer**: HTML5 Canvas를 이용한 2D 경기 중계 시뮬레이션.
*   **Skill Moves**: 마르세유 턴, 엘라스티코, 사포 등 선수들의 화려한 개인기 구현.

### 2. 깊이 있는 전술 시스템 (DNA)
*   **라인별 DNA 설정**: 공격, 미드필더, 수비진의 성향(스피드, 기술, 피지컬 등)을 세부적으로 조정.
*   **전술 상성**: 게겐프레싱, 티키타카, 텐백 등 9가지 메인 전술 간의 가위바위보 식 상성 로직.
*   **Deep Tactics**: 수비 라인 높이, 압박 강도, 패스 스타일 등 세부 지시 가능.

### 3. 역동적인 이적 시장 및 성장
*   **AI 이적 시뮬레이션**: 유저뿐만 아니라 AI 팀들 간에도 지능적인 선수 거래가 발생합니다.
*   **포텐셜 시스템**: 25세 이하 유망주들의 실시간 능력치 성장 및 관리.
*   **은퇴 및 환생**: 노장 선수의 은퇴 후 유스팀에서 해당 선수의 재능을 이어받은 환생 선수 등장.

### 4. 다양한 게임 모드
*   **Regular League**: 1부에서 3부까지 이어지는 승강제 시스템.
*   **Legend League**: 축구 역사의 전설적인 아이콘 팀들로만 구성된 특별 리그.
*   **World Cup Mode**: 48개국이 참여하는 토너먼트 방식의 월드컵 모드 (조별리그 및 32강 토너먼트).

### 5. 매니지먼트 요소
*   **SNS 시스템**: 인스타그램 스타일의 피드와 Gemini AI를 이용한 현실적인 팬들의 댓글 반응.
*   **비서 상담**: 비서 '김지수'와의 상담을 통한 팀 사기 진작 및 전술 조언.
*   **스폰서 계약**: 팀의 명성에 따른 차등 스폰서십 체결 및 자금 확보.

---

## 🛠 기술 스택

*   **Frontend**: Vanilla JavaScript, HTML5, CSS3 (Bento UI 디자인)
*   **Backend**: Node.js, Express (Gemini API 프록시 서버)
*   **AI**: Google Gemini API (SNS 댓글 생성 및 전술 분석 도움)
*   **Graphics**: Canvas API (Match Visualizer), Chart.js (DNA 레이더 차트)
*   **Storage**: LocalStorage (세이브 슬롯 시스템)

---

## 🎮 조작 가이드 및 단축키

*   **선수 교체**: 경기 중 `교체` 버튼을 눌러 최대 5명까지 교체 가능 (부상 시 강제 교체 발생).
*   **단축키**:
    *   `Shift + F`: 경기 진행 속도 고속 모드 토글.
    *   `Ctrl + Shift + S`: 5시즌 즉시 시뮬레이션 (테스트용).
*   **게임패드 지원**: Xbox/PS 컨트롤러를 연결하여 커서 이동 및 메뉴 선택 가능 (진동 피드백 포함).

---

## 📂 프로젝트 구조

*   `script.js`: 게임 데이터 초기화 및 메인 로직.
*   `tacticSystem.js`: 매치 엔진 및 경기 진행 시스템.
*   `transfer.js`: 이적 시장 및 AI 영입 로직.
*   `playerGrowth.js`: 선수 성장 및 포텐셜 계산.
*   `worldcup.js`: 월드컵 모드 전용 로직.
*   `visibleMatch.js`: 경기 시각화 엔진.
*   `sns.js`: SNS 피드 및 댓글 시스템.
*   `server.js`: API 보안을 위한 프록시 서버.

---

## ⚙️ 실행 방법

1.  로컬 환경에서 `index.html`을 엽니다.
2.  AI 댓글 기능을 사용하려면 서버를 실행해야 합니다:
    ```bash
    npm install
    # .env 파일에 GEMINI_API_KEY 설정 필요
    node server.js
    ```
3.  브라우저에서 접속하여 팀을 선택하고 감독 커리어를 시작하세요!
